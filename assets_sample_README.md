# Sample Assets

Place your demo files here for local testing:

- `input.mp4` — a short sample source video (front-facing speaker, a few seconds)
- `voice_ref.wav` — a clean 6+ second reference clip of the voice to clone (optional; defaults to input.mp4's own audio)

These are gitignored except this README — don't commit large media files to the repo. Consider Git LFS if you need to version sample media.
